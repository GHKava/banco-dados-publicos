## Objetivo

Implementar lógica de decisão de compliance (policy gate) que determina automaticamente o nível de acesso permitido para cada fonte de dados:

- **DENY**: Bloqueio completo (não consta na allowlist, ToS proíbe, robots.txt bloqueia, etc.)
- **METADATA_ONLY**: Apenas metadados podem ser coletados (título, URL, data, autor) — sem fulltext
- **FETCH_PUBLIC**: Fetching permitido, mas uso restrito a contextos públicos
- **FULL_ACCESS**: Acesso irrestrito (license permite, ToS permite, robots.txt OK)

**Policy Gate** deve ser **fail-closed**: qualquer dúvida = nível mais restritivo.

1. `configs/sources.yaml` — Definições de fontes com metadata de compliance
2. `src/bots/validators.py` — Funções de validação existentes (allowlist, license, robots)

## Saídas

1. **Arquivo principal:** `src/bots/policy_gate.py`
   - Classe `PolicyGate` com método `get_access_level(source_id: str, url: str | None = None) -> str`
   - Retorna: "DENY", "METADATA_ONLY", "FETCH_PUBLIC", ou "FULL_ACCESS"
   - Lógica:
     ```python
     if not in_allowlist(source_id):
         return "DENY"
     if not has_valid_license(source_id):
         return "METADATA_ONLY"
     if not robots_allows(url):
         return "DENY"
     # ... outras regras
     return "FULL_ACCESS"  # ou menor nível conforme ToS
     ```

## Riscos e Edge Cases

1. **Missing data em sources.yaml:**
   - Policy: Fail-closed → METADATA_ONLY ou DENY
   - Registrar DUV se impactar muitas fontes

2. **Conflito entre allowlist e robots.txt:**
   - Allowlist = política interna (ACCEPT)
   - Robots.txt = política do site (RESPECT)
   - Decisão: Robots.txt prevalece (legal safety)

3. **Ausência de licença explícita:**
   - Default: METADATA_ONLY (safe harbor)

4. **URLs dinâmicas ou CDNs:**
   - Validar contra robots.txt do domínio raiz
   - Se indeterminado: METADATA_ONLY

5. **Performance:**
   - Cache de decisões por source_id (revalidar a cada 24h?)
   - Não fazer chamadas HTTP síncronas no policy gate (assume dados já coletados)

## Exemplos de Uso

```python
from src.bots.policy_gate import PolicyGate

gate = PolicyGate()

# Cenário 1: Source OK, robots OK
level = gate.get_access_level("SRC-001", "https://www.in.gov.br/leiturajornal")
assert level == "FULL_ACCESS"

# Cenário 2: Source não na allowlist
level = gate.get_access_level("SRC-999", "https://example.com/")
assert level == "DENY"

# Cenário 3: Robots.txt bloqueia
level = gate.get_access_level("SRC-001", "https://www.in.gov.br/admin/")
assert level == "DENY"

# Cenário 4: Source sem licença
# (assumindo sources.yaml modificado para teste)
level = gate.get_access_level("SRC-003", "https://servicodados.ibge.gov.br/api/...")
assert level == "METADATA_ONLY"
```
