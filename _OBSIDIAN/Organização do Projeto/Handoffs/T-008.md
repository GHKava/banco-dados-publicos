## O que foi feito

Implementada e validada a lógica de **Policy Gate** para decisões automáticas de compliance. O PolicyGate determina o nível de acesso permitido para cada fonte de dados com base em 5 regras:

1. **Allowlist:** Apenas sources SRC-001 a SRC-005 são permitidas
2. **License:** Licenças permissivas (public_domain, cc0, open_government_license) → ALLOW; desconhecidas → METADATA_ONLY
3. **Robots.txt:** Respeito obrigatório; disallow → BLOCK; crawl_delay >5s → METADATA_ONLY
4. **ToS:** Prohibition keywords → BLOCK; silêncio (gov sites) → ALLOW
5. **PII:** High PII sem redaction → BLOCK; high/medium com redaction → METADATA_ONLY

**Design:** Fail-closed — qualquer ambiguidade resulta no nível mais restritivo.

## Decisões técnicas

1. **Fail-closed por padrão:** Ambiguidade → METADATA_ONLY ou BLOCK (não ALLOW)
2. **Government domains (.gov.br) recebem benefit of doubt:** Missing license em .gov → METADATA_ONLY (não BLOCK)
3. **Robots.txt prevalece sobre allowlist:** Respeito legal às políticas do site
4. **PII alto requer redaction plan:** High PII sem mitigação → BLOCK
5. **Crawl delay >5s sinaliza relutância:** Site quer "slow down" → METADATA_ONLY

## Como usar

```python
from src.bots.policy_gate import PolicyGate, PolicyDecision

gate = PolicyGate()  # fail_closed=True por padrão

# Exemplo 1: Source na allowlist com licença permissiva
source = {
    "source_id": "SRC-001",
    "url": "https://www.in.gov.br/",
    "metadata": {
        "license_policy": {
            "license_type": "public_domain",
            "license_status": "verified"
        },
        "crawl_policy": {"robots_respect": True},
        "data_handling": {"pii_expected": "low"}
    }
}
decision = gate.evaluate(source)
assert decision == PolicyDecision.ALLOW

# Exemplo 2: Source não na allowlist
source_blocked = {"source_id": "SRC-999", "url": "https://example.com", "metadata": {}}
decision = gate.evaluate(source_blocked)
assert decision == PolicyDecision.BLOCK

# Exemplo 3: Licença desconhecida em .gov
source_metadata = {
    "source_id": "SRC-002",
    "url": "https://www.planalto.gov.br/",
    "metadata": {
        "crawl_policy": {"robots_respect": True},
        "data_handling": {"pii_expected": "low"}
    }
}
decision = gate.evaluate(source_metadata)
assert decision == PolicyDecision.METADATA_ONLY
```

## Observações

- **Policy gate NÃO faz fetching:** Usa dados em memória/cache de `configs/sources.yaml`
- **Decisões são baseadas em metadata:** Para atualizar robots.txt ou ToS, usar bot específico (T-009)
- **Fail-closed é crítico para compliance:** Melhor bloquear incorretamente do que permitir incorretamente (legal risk)
- **Government domains são trusted:** Dados governamentais geralmente são públicos (Lei de Acesso à Informação no Brasil)
