## Design Highlights

### Compliance-First

- `default_storage_mode`: METADATA_ONLY by default (fail-closed)
- PII detection columns in documents table
- Audit log for all operations
- Retention policies per source

### Performance

- HNSW index on embeddings for fast vector search
- Indexes on hash columns for deduplication
- Filtered indexes (e.g., WHERE is_duplicate = FALSE)

### Extensibility

- Version tracking for documents
- JSONB columns for flexible metadata (entities, topics, pii_detected)
- Chunk method tracking for A/B testing different chunking strategies
