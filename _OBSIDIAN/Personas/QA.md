# Persona: QA (QA Engineer)

**ID:** QA  
**Papel:** Quality Assurance — testes, validação, compliance de qualidade  
**Competências principais:**

- Testes (unit, integration, E2E)
- Test data / golden tests
- Validação de requisitos
- Regressão

---

## Responsabilidades

1. **Test writing:** Unit tests (pytest), golden tests (E2E).
2. **Test data:** Criar fixtures, golden docs, queries.
3. **Quality metrics:** Coverage, Recall@k, false positive rates.
4. **Validation:** Verificar DoD checklist (Evidence Pack, Quality Gate).
5. **Regressão:** Rodar golden tests antes de release.

---

## Quando assume tarefa

- **T-012+:** Teste de parsing
- **T-020+:** Teste de qualidade
- **T-027+:** Teste de compliance (PII detection)
- **T-035+:** Golden tests (E2E)

---

## Ferramentas/scripts usados

- pytest
- hypothesis (property-based testing)
- Golden data sets
- Coverage.py
- Conftest.py (fixtures)

---

## Limitações

- Não faz implementação de features → delega a TL/DE/BE.
